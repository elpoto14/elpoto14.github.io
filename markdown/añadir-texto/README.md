# INTRODUCIR TEXTO EN MULTIPLES FORMATOS EN MARKDOWN

vamos a introducir texto en multiples formatos en markdown como titulos, listas, y demas cosas utiles para que podais crear vuestros repositorios de manero profesional VAMOS AL LIO!!!

introducr texto en markdown es bastante sencillo y practicando un poco ya se te va quedando. y recuerda que los comandos se escriben sin las comillas, las comillas son para comentar el texto y que se vea el comando

## TITULOS.

para escribir un titulo osease un texto en grande lo pondremos de la siguiente manera

````
# titulo de ejemplo
````

resultado:

# titulo de ejemplo

para añadir un subtitulo osease un texto un poco mas pequeño lo haremos asi

````
## subtitulo de ejemplo
````

resultado:

## subtitulo de ejemplo

para una seccion o apartado lo haremos de la siguiente manera 

````
### seccion o apartado texto pequeño
````

resultado:

### seccion o apartado texto pequeño

---

## LISTAS

tambien podemos hacer listas en markdown y es basatante sencillo de echo, para hacer una lista pondremos lo siguiente 

lista simple:

````
* elemento 1
* elemento 2
* elemento 3
````

resultado:

* elemento 1
* elemento 2
* elemento 3

## CHECKLIST ESTILO TAREA O COMPROBACION

estas listas son utiles para hacer comprobaciones de tareas realizadas o tareas pendientes de realizar el chek podemos añadirlo o quitarlo nosotros mismos en markdown, para marcar un elemento como realizado pondremos una x dentro de los corchetes del elemento en cuestion, si la tarea no esta realizada dejaremos los corchetes vacios 

para hacer este tipo de listas lo haremos asi 

````
- [x] actualizar el sistema
- [x] reiniciar el sistema
- [ ] instalar los programas
- [ ] comprobar temperaturas
````

resultado:

- [x] actualizar el sistema
- [x] reiniciar el sistema
- [ ] instalar los programas
- [ ] comprobar temperaturas
